# 问题记录 — 2026-04-04

## 问题 1：swtpm 安装时警告主目录不可访问

**现象**：
```
警告：您指定的主目录 /var/lib/swtpm 不能够访问：No such file or directory
```

**原因**：`apt` 安装 `swtpm` 时会创建系统用户 `swtpm`，但其主目录 `/var/lib/swtpm` 尚未创建。

**影响**：无。我们使用 `swtpm socket` 模式，状态存储在自定义目录 `/tmp/tpm-state`。

**处理**：忽略，不影响使用。

## 问题 2：mssim TCTI 无法连接 swtpm

**现象**：
```
export TPM2TOOLS_TCTI="mssim:host=localhost,port=2321"
tpm2_pcrread sha256:0

WARNING:tcti:src/tss2-tcti/tcti-mssim.c:473:simulator_setup() Failed to send MS_SIM_NV_ON platform command.
ERROR: Could not load tcti, got: "mssim:host=localhost,port=2321"
```

**原因**：`mssim` TCTI 是为微软官方 TPM 模拟器设计的。它在连接后会向控制端口（2322）发送 `MS_SIM_NV_ON` 平台命令，但 `swtpm` 的控制通道使用不同的协议，不认识该命令。

**解决**：使用 `swtpm` 专用 TCTI：
```bash
export TPM2TOOLS_TCTI="swtpm:host=localhost,port=2321"
```

**两者区别**：
| | mssim | swtpm |
|---|-------|-------|
| 命令通道 (2321) | 兼容 | 兼容 |
| 控制通道 (2322) | 微软协议 (MS_SIM_NV_ON) | swtpm 自有协议 |
